────────────────────────────────────────────────────────────────────
RESET TO CLEAN SEED STATE
────────────────────────────────────────────────────────────────────

  Stop the API (Ctrl+C in the uvicorn terminal), then from backend/:

  Remove-Item tan90.db          (macOS/Linux: rm tan90.db)
  python -m app.db.seed
  uvicorn app.main:app --port 8001 --reload

  Starting the API on an empty database seeds it automatically, so the
  python -m app.db.seed step is optional.
